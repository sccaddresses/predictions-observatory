# SCC Predictions Observatory

Public, publication-safe output from the private `sccaddresses/predictions-research` research repository.

This repository is intentionally limited to public website assets, prospective prediction outputs, evaluation summaries and selected reports. Raw research data, credentials, provider payloads and private working material remain in the private research repository.

**Status:** prospective forecasting research / forward validation.

The automated publication workflow in the private research repository updates this repository after pre-race freezes and post-race evaluations.
